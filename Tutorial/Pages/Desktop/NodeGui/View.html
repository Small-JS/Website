View class - central widget.
QWidget is the central GUI element of NodeGui.
It can contain GUI elements, but also entire window panes.
A window can have a CSS stylesheet, to facilitate static styling.

(The view operations coded into the app class here,
but a separate view class cloud be more reusable.)
