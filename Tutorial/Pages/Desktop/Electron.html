Desktop - Electron
Electron is the most popular desktop framework in the world,
for making multi-platform apps that also have a web app version.
Its eco-system is large and support is good.
However, compared to NW.js, Electron require (far) more memory and are more complex to develop in,
because of the strict separation of the Node.js and the browser environments that every app needs.

Encapsulation of Electron in SmallJS has been minimally done for the example app,
so is it far from complete. Nw.js is the recommended framework to use for desktop apps now.
If somebody has a good Electron specific use case to implement in SmallJS
and maybe wants to help expand Electron encapsulation in SmallJS,
please create an issue in the SmallJS repo.
