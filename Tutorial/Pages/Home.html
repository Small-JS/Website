Create a Tic-tac-toe game in SmallJS using Claude AI!

AI can be a great help to get you started in SmallJS quickly.
This video shows how to make a fully working Tic-tac-toe game in SmallJS using Claude AI.
Claude generates all code including unit and GUI tests with just simple prompts.
It starts form a working Counter app (the AI 'harness')
and has access to a file with SmallJS contextual knowledge.
The generated code is concise, clear and commented, so maintainable by humans.

Youtube link: www.youtube.com/watch?v=4_ir6h2MIRg
The repo folder ./Contributions/Tictactoe contains the generated result.
